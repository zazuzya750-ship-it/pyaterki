# Долг пятёрками

Сын отдаёт долг пятёрками. Русский, математика и чтение стоят по 200 ₽ за пятёрку, остальные предметы по 100 ₽. Приложение показывает остаток, списания по предметам и дневник с датами.

- Данные общие и хранятся в Supabase.
- Изменения сразу появляются у всех, у кого открыто приложение.
- Вносить изменения может любой, у кого есть ссылка.
- Приложение можно поставить на экран телефона как обычное.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Страница: вёрстка и стили |
| `app.js` | Логика приложения |
| `config.js` | Адрес и публичный ключ Supabase (заполнить!) |
| `supabase.js` | Библиотека Supabase (supabase-js 2.117.2) |
| `sw.js`, `manifest.webmanifest`, `icon*.png`, `icon.svg`, `apple-touch-icon.png` | Всё для установки на телефон и работы без интернета |
| `supabase.sql` | Таблицы и права доступа: один раз выполнить в Supabase |

## Настройка, около 10 минут

### 1. Supabase
1. Откройте [supabase.com/dashboard](https://supabase.com/dashboard) и создайте проект (New project). Регион выберите любой близкий, например Frankfurt.
2. Откройте **SQL Editor → New query**, вставьте содержимое `supabase.sql` целиком и нажмите **Run**. Должно появиться сообщение `Success`.
3. Откройте **Project Settings → API Keys** (или **Data API**) и скопируйте две вещи:
   - **Project URL**, вида `https://abcdefgh.supabase.co`;
   - публичный ключ: **Publishable key** (`sb_publishable_…`) или **anon public**.
4. Впишите их в `config.js`.

> Ключ `secret` или `service_role` в `config.js` не вставляйте: этот файл видят все.

### 2. GitHub Pages
1. На [github.com/new](https://github.com/new) создайте репозиторий, например `pyaterki`, с видимостью **Public**. На бесплатном тарифе Pages работает только для публичных репозиториев.
2. Нажмите **Add file → Upload files**, перетащите все файлы из этой папки и нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В поле **Source** выберите **Deploy from a branch**, ветку `main`, папку `/ (root)` и нажмите **Save**.
4. Через минуту-две приложение будет доступно по адресу `https://ВАШ-ЛОГИН.github.io/pyaterki/`. Эту ссылку и отправляйте сыну.

### 3. Установка на телефон
- **iPhone:** откройте ссылку в Safari, нажмите «Поделиться» и выберите «На экран „Домой“».
- **Android:** откройте ссылку в Chrome и нажмите кнопку «Установить» в приложении или пункт меню «Установить приложение».

## Что важно знать
- **Изменять может любой, у кого есть ссылка:** и записывать, и удалять. Так и задумано. Не выкладывайте ссылку в открытый доступ.
- **Бесплатный проект Supabase засыпает после 7 дней без обращений.** Если неделю никто не открывал приложение, оно покажет «Не удалось загрузить данные». Тогда зайдите в панель Supabase и нажмите **Restore project**. Данные при этом не теряются.
- **Как обновить приложение:** загрузите изменённые файлы в репозиторий тем же способом. Телефоны подхватят новую версию при следующем открытии.
